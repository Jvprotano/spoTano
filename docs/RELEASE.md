Aplicação desktop Windows x64 com biblioteca SQLite, múltiplas playlists Spotify,
downloads via spotDL 4.6.0, gêneros opcionais, correções manuais, sincronização
incremental com prévia e exportação USB verificada por SHA-256.

Baixe o ZIP, extraia a pasta inteira e abra **spoTano.exe**. Não exige instalar
Python. No primeiro uso, abra **Configurações → Preparar downloads** para FFmpeg
e Deno (requer internet). Depois adicione playlists públicas e clique Atualizar.

Downloads dependem de disponibilidade e permissão do provedor. Compatibilidade
com o rádio físico do Cerato 2011 não foi certificada. Veja README e
docs/VALIDATION.md para testes, funcionamento e limitações.
